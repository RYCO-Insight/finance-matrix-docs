# Finance Matrix - Support

Publisher: RYCO Insight AS

## About

Finance Matrix is a configurable financial statement matrix visual for Microsoft Power BI, built for Income Statement, Balance Sheet, and Cash Flow reporting. It supports custom rows, conditional formatting, multi-level column hierarchies, and image/SVG rendering in cells, among other features.

## Compatibility

Finance Matrix works in Power BI Desktop and the Power BI service, wherever custom visuals are supported by your organization's tenant settings.

# Finance Matrix - Support (norsk)

Utgiver: RYCO Insight AS

## Om

Finance Matrix er en konfigurerbar finansiell rapporteringsmatrise for Microsoft Power BI, bygget for resultatregnskap, balanse og kontantstrømrapportering. Den støtter egendefinerte rader, betinget formatering, flernivå kolonnehierarkier, og bilde/SVG-rendering i celler, blant annet.

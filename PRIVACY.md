# Finance Matrix - Privacy Policy

Last updated: September 15, 2026
Publisher: RYCO Insight AS
Contact: haakon.rykkje@rycoinsight.com

## Overview

Finance Matrix ("the visual") is a custom visual for Microsoft Power BI, developed and published by RYCO Insight AS. This policy explains how the visual handles data.

## Data processing

The visual runs entirely within the Power BI report canvas, in the same sandboxed environment as any other Power BI visual. It does not:

- Transmit report data to any external server operated by RYCO Insight or by any third party
- Use cookies, browser storage, or tracking technologies
- Collect telemetry, usage analytics, or personal information about report viewers
- Make any network request outside of Power BI's own hosting environment

## Data you provide to the visual

Any data the visual displays comes directly from the Power BI report's own data model, exactly as configured by the report author. RYCO Insight has no access to this data and does not receive, store, or process it in any way, at any point.

## Changes to this policy

RYCO Insight may update this privacy policy from time to time. The "Last updated" date above reflects the most recent revision.

## Contact

# Personvernerklæring - Finance Matrix

Sist oppdatert: 15. september 2026
Utgiver: RYCO Insight AS

## Oversikt

Finance Matrix ("visualen") er et egendefinert visual for Microsoft Power BI, utviklet og publisert av RYCO Insight AS. Denne erklæringen forklarer hvordan visualen behandler data.

## Databehandling

Visualen kjører utelukkende i Power BI-rapportens eget lerret, i det samme sandkasse-miljøet som alle andre Power BI-visualer. Den:

- Sender ikke rapportdata til noen ekstern server driftet av RYCO Insight eller av tredjepart
- Bruker ikke informasjonskapsler, nettleserlagring eller sporingsteknologi
- Samler ikke inn telemetri, bruksstatistikk eller personopplysninger om rapportbrukere
- Gjør ingen nettverkskall utenfor Power BIs eget vertsmiljø

## Data du gir til visualen

All data visualen viser kommer direkte fra Power BI-rapportens egen datamodell, slik den er konfigurert av rapportforfatteren. RYCO Insight har ingen tilgang til denne dataen, og mottar, lagrer eller behandler den ikke på noen måte, på noe tidspunkt.
